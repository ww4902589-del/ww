# QA Evidence Requirements V7

Every completed stage needs evidence.

## Stage 1 Assets

Required:

- PSD layer screenshot
- layer list
- repaired occlusion examples
- asset validation report

## Stage 2 Cubism

Required:

- Cubism Viewer screenshot
- model files
- parameter list
- blink close-up
- physics check

## Stage 3 Runtime

Required:

- console load record
- no duplicate character render
- interaction regression

## Stage 4 Final

Required:

- Wallpaper Engine capture
- 12 second loop video
- 0s/12s comparison
- performance report

No evidence means stage is not complete.
