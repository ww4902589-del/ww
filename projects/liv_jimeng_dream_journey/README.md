# 丽芙·霁梦：溯梦归途

Wallpaper Engine 互动动态壁纸工程。

当前基线为 v5 服装与动态强化版：人物服装依据官方参考重构为连续月白布料、羽瓣式肩装与冰蓝丝质裙层，移除胸腹与裙装的大面积网格结构。工程包含人物吸气伸手关键帧、眨眼关键帧、人物分区动画、指尖—晶体鼠标光路和画布艺术标题。

本仓库中的 JavaScript 按加载顺序拆分到 `src/`，行为与原始 `app.js` 基线一致，便于后续 Codex 子代理分别处理人物、背景、标题和运行时逻辑。

## 已实现的基线功能

- 12 秒首尾连续的镜头呼吸与星尘循环
- 人物吸气、伸手与局部眨眼叠加
- 鼠标视差与跟随微光
- 鼠标靠近人物手与晶体时增强回应、改变光束弧线并点亮胸前核心
- 左键点击晶体涟漪，1 秒触发冷却
- Wallpaper Engine 音频监听与中等强度响应
- 高、中、低画质粒子档位
- 冰蓝、粉白、淡紫及自动昼夜主题
- 1 分钟无操作后进入静谧模式
- 程序化艺术标题与可选晶体环境音
- 超宽屏 Cover 适配、缩放与水平位置调节

## v6 目标

- 人物以缓慢转头为主动作。
- 保留呼吸、手臂前送、手指、头发、裙摆和飘带辅助动作。
- 眨眼频率保持为 12 秒两次，但改为局部眼睑/眼睛素材实现，消除虚影。
- 增强星河转动、碎片分层浮动、晶体流光和局部星尘运动。
- 保持现有互动、音频、标题、设置面板和静谧模式。

详细限制和执行顺序见 `AGENTS.md` 与 `TASKS.md`。

## 使用

1. 按 `assets/ASSET_MANIFEST.md` 恢复二进制素材。
2. 在 Wallpaper Engine 中打开“壁纸编辑器”。
3. 选择“打开项目”，定位到本目录的 `project.json`。
