# V8 真实帧素材生产规范

## 目标

生产真实透明 PNG 帧素材，驱动多图片动态壁纸。

当前工程不是整图移动方案，而是：

```
独立图层
+
固定锚点
+
连续帧
+
时间轴调度
```

## 基础规格

- 画布：1920×1080
- 格式：PNG
- 必须 Alpha 透明
- 同一角色身份
- 同一构图比例
- 同一光照方向
- 同一颜色体系

## 禁止内容

禁止生成：

- 光噪
- 随机闪点
- 锁链纹路
- 链条装饰
- AI纹理漂移
- 双眼重影
- 手指畸变
- 整张图片拉伸模拟动作

## 生产顺序

### 第一阶段：角色基准

生成：

```
body_base.png
head_00.png
arm_00.png
hair_back_00.png
hair_front_00.png
```

确认角色一致后再扩展。

---

## 第二阶段：头部动作

数量：9

```
head_00
head_01
...
head_08
```

动作要求：

- 头部整体旋转
- 颈部连接自然
- 发丝跟随变化
- 五官比例不变

禁止：

- 只改变脸
- 脸型漂移
- 眼睛位置变化

---

## 第三阶段：眼睛

数量：5

```
eye_open
eye_half
eye_closed
eye_half_return
eye_open_hold
```

要求：

- 只包含眼睛区域
- 不包含眉毛大面积变化
- 不改变脸部

---

## 第四阶段：手臂动作

数量：9

必须体现：

```
肩部
 ↓
肘部
 ↓
手腕
 ↓
手指
```

禁止：

- 整个手臂平移
- 复制粘贴手
- 手指数量变化

---

## 第五阶段：背景

独立生产：

```
starfield_far
starfield_mid
starfield_near
crystal_glow
fragments
memories
```

要求：

- 不同速度
- 不同相位
- 可隐藏/显示

---

## 验收顺序

1. 角色一致性
2. 手部结构
3. 眼睛无重影
4. Alpha边缘
5. 背景运动
6. 12秒循环闭合

未通过验收，不进入运行阶段。
