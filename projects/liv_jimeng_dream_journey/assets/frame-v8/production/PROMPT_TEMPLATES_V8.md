# V8 多帧素材生产模板

> 本文件用于真实素材制作，不是让模型独立重画 79 张彼此无关的图片。

## 1. 总原则

每一组动画必须使用“母帧 → 相邻帧局部编辑”的方式生产。

固定不变：

- 角色身份、脸型、五官比例、发饰、服装结构与色彩关系；
- 1920×1080 画布；
- 全画布坐标和透明区域；
- 头颈、肩、肘、腕等锚点；
- 非运动区域的像素与轮廓；
- 光源方向、线稿粗细和阴影风格。

禁止：

- 每张帧图从零独立生成；
- 整张人物旋转、拉伸或平移来冒充动作；
- 光点噪声、发光脏点、随机闪烁颗粒；
- 锁链、链环、束缚装置和相似机械纹样；
- 多余肢体、畸形手指、双眼皮重影、双睫毛；
- 黑底或白底抠图、半透明污染边；
- 在透明层中重画不属于该层的身体或背景。

## 2. 通用编辑模板

将方括号内容替换为当前资产信息：

```text
以参考母帧 [SOURCE_FRAME] 为唯一基础进行局部编辑，输出 [TARGET_FILE]。
画布固定为 1920×1080，保持所有非编辑区域像素、角色身份、服装结构、线稿、色彩、阴影和锚点不变。
仅修改 [EDIT_REGION]，目标变化为：[MOTION_DESCRIPTION]。
该文件只包含 [LAYER_CONTENT]；其余区域必须完全透明。
边缘必须干净，不得出现白边、黑边、半透明矩形、发光噪点或锁链/束缚纹样。
不要添加文字、水印、粒子、额外饰品或其他身体部件。
输出非索引色 RGBA PNG，1920×1080。
```

负面约束：

```text
identity drift, different face, different costume, different body proportion,
extra fingers, missing fingers, fused fingers, broken wrist, duplicate eyelashes,
double iris, face patch, rectangular alpha patch, white matte, black matte,
glow noise, glitter dust, random luminous dots, chain, chain link,
restraint device, full-image rotation, full-image scaling, crop animation,
text, logo, watermark
```

## 3. 基础母版

### `body_base.png`

只保留躯干和不参与独立动画的主体部分。不得包含头部、眼睛层、独立手臂、前后发、裙摆、飘带、晶体、碎片或标题。

```text
从已批准的角色母图中精确分离静态躯干主体，保持人物身份、服饰和比例不变。
移除并透明化头部、独立手臂、前发、后发、眼睛局部层、裙摆、飘带和所有背景元素。
修复被移除层遮挡的接缝区域，使后续图层组合时没有破洞，但不得虚构新的服装设计。
```

### `background_clean.png`

```text
重建没有人物、碎片、晶体、标题和记忆晶片的干净场景底图。
保留原场景空间关系和主色，不添加星尘噪点、链环或新装置。
该文件允许为不透明 PNG；人物原遮挡区需要自然补全。
```

### `crystal_base.png`

只保留右侧主要晶体的非发光实体部分，透明背景；不得包含发光晕、星点和人物。

### `title_base.png`

只保留批准的艺术标题图层；需要透明背景。若继续由 HTML 标题呈现，可制作透明空缺替代方案前必须修改 manifest，不得放置空 PNG 占位。

## 4. 头部序列 `head_00`—`head_08`

母帧：`head_00.png`。

锚点：颈部连接点必须保持在 `sprite-layout-v8.json` 规定位置，误差不超过 3 px。

| 文件 | 编辑目标 |
|---|---|
| `head_00.png` | 正面/初始姿态，循环首帧 |
| `head_01.png` | 轻微开始转向，五官透视变化约 10% |
| `head_02.png` | 转向约 25%，近侧脸颊和耳侧发丝相应变化 |
| `head_03.png` | 转向约 45%，鼻梁、眼距和下颌轮廓出现真实透视变化 |
| `head_04.png` | 转向约 70%，颈部连接仍固定 |
| `head_05.png` | 动作峰值，克制而自然，不改变角色气质 |
| `head_06.png` | 从峰值开始返回，不得直接复制 `head_04`；保留轻微惯性差异 |
| `head_07.png` | 接近初始姿态，轮廓连续 |
| `head_08.png` | 与 `head_00` 视觉闭环，接缝检查通过 |

头部专用提示：

```text
只编辑头部及与转头直接相关的局部发丝和颈部接缝。
转向必须由脸部透视、下颌轮廓、鼻梁、双眼位置和发丝遮挡关系共同体现，禁止把整张头部图层机械旋转。
眼睛保持睁开基准状态，眨眼由独立 eyes 层完成。
```

## 5. 眼睛序列

文件：

- `eye_open.png`
- `eye_half.png`
- `eye_closed.png`
- `eye_half_return.png`
- `eye_open_hold.png`

眼睛层只能覆盖眼睛和必要睫毛区域。鼻、嘴、脸颊、前发必须透明。

```text
以 eye_open 为母帧，只改变上下眼睑和睫毛形态。
虹膜在闭眼过程中被眼睑自然遮挡，不得半透明残留；不得出现双睫毛、双虹膜、灰色眼雾或矩形脸部补丁。
eye_half_return 与 eye_half 允许存在极轻微非对称差异，但必须保持同一眼位。
```

## 6. 手臂序列 `arm_00`—`arm_08`

锚点：肩点误差不超过 3 px。动作必须至少包含肩、肘、腕/手指三个结构变化。

| 文件 | 编辑目标 |
|---|---|
| `arm_00.png` | 初始放松姿态 |
| `arm_01.png` | 肩部开始抬起，肘部轻微改变 |
| `arm_02.png` | 上臂继续抬起，前臂方向发生变化 |
| `arm_03.png` | 开始伸展，肘角明显但自然变化 |
| `arm_04.png` | 接近最大伸展，腕部开始响应 |
| `arm_05.png` | 峰值保持，手指姿态稳定且自然 |
| `arm_06.png` | 腕部/手指细微转向，不能只是整臂平移 |
| `arm_07.png` | 返回过程，保留惯性差异 |
| `arm_08.png` | 回到初始并与 `arm_00` 闭环 |

手臂专用提示：

```text
只编辑独立手臂层。肩部连接点固定，动作沿肩关节、肘关节、腕关节连续传播。
保持手指数量、长度和关节结构一致。禁止橡胶臂、拉伸手掌、粘连手指、突然改变袖口或饰品。
```

## 7. 头发和布料

### 后发 `hair_back_00`—`hair_back_04`

从静止到轻微飘起再返回。根部固定，末端变化大于根部；不得改变总发量或发饰。

### 前发 `hair_front_00`—`hair_front_04`

变化幅度小于后发，且不得遮挡眼睛层的关键区域。与头部转向保持空间一致。

### 裙摆 `skirt_00`—`skirt_03`

腰部连接固定，褶皱传播连续；不得改变服装长度、开衩或暴露程度。

### 飘带 `ribbon_00`—`ribbon_03`

固定根部，末端形成柔和 S 型变化；不得生成链条、金属束缚结构或新的装饰。

## 8. 背景层

### 星河

- `starfield_far_00`—`03`
- `starfield_mid_00`—`03`
- `starfield_near_00`—`03`

```text
制作稀疏、可辨认的大型星河纹理和柔和云带，不使用密集随机发光点。
远、中、近三层必须在尺度、密度和运动方向上可区分；透明背景。
四相位首尾应可循环，不得出现亮度突跳。
```

### 晶体发光 `crystal_glow_00`—`03`

只包含晶体内部光路和柔和边缘流光；禁止高频闪烁、脏点、爆闪和全屏泛白。

### 碎片

- `frag_lt_00`—`02`
- `frag_top_00`—`02`
- `frag_mid_00`—`02`
- `frag_rb_00`—`02`

每个碎片保持同一几何身份，只改变位置透视、轻微旋转和明暗；不得变成链环或机械束缚件。

### 记忆晶片 `memory_01`—`06`

每张为独立内容层，边缘清晰、可淡入淡出；内容不得堆砌，不能覆盖人物脸部。

## 9. 每批次提交要求

每批次必须同时提交：

1. PNG 文件；
2. 本批次的母帧名称；
3. 使用的局部编辑说明；
4. `manual-review-v8.json` 中对应检查项；
5. `node scripts/verify_frame_assets.js` 的 JSON 报告；
6. 接缝对比图或 12 秒预览视频，仅作为 QA 证据，不替代 PNG。

任何批次出现身份漂移、手指畸形、眼睛重影、光噪或锁链纹路，整批退回，不进入下一组。
