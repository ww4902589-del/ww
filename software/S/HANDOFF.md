# S / ComfyBatch V2.21 交接：紧凑审图与半透明信息浮层

## 本次交付

任务清单第 10 项。审图页（阶段 4）的两个补强：

- **缩略图墙（`wall` 密度档）**：密度下拉新增第四档——150px 小图一格、正方形裁切、
  kv 表／生成详情／提示词块全部收起，只留图、标题行（含勾选框与徽标）和缩小的
  操作按钮。给「几十上百张图快速过一遍」用。默认档位仍是「紧凑」，墙档是 opt-in。
- **半透明信息浮层（`.thumb-overlay`）**：悬停（或键盘聚焦）缩略图时浮出暗色渐变
  信息条——编号、尺寸（含放大倍数）、种子、确认状态（疑似重复会标注）、提示词摘要
  （前 140 字 / 3 行）。**所有密度档都可用**；墙档下它是唯一的信息入口。

设计取舍与"不要优化掉"的清单见 `docs/22-紧凑审图与信息浮层_V2.21.md`。
要点：浮层纯 CSS 驱动（零 JS 监听）、`pointer-events:none` 保证永不挡点击
（有测试钉住）、`aria-hidden` 避免读屏器双读、墙档必须保留操作按钮（有测试钉住）。

与 #11 的边界：编号跳转、高亮增强、滚动定位、快捷键全部留给 #11，本分支
**没有引入任何键盘事件**。密度记忆沿用既有 localStorage 键
`comfybatch-review-density`，`setReviewDensity` 按值加类，`wall` 无需改 JS 逻辑。
