## 已知限制

- 「删除档案」按钮挂在已选 LoRA 行内（软件没有独立的档案管理列表），未选中的 LoRA 档案暂不能删
- 批量打回不支持「改提示词」模式（多张无法共用一段替换词），后端两层均拦截
- 疑似重复判定是强条件（同种子+同提示词），同种子不同提示词不算重复
