# V2.20：链接图片提取（2026-09-22）

## 目标

把公开网页、图片直链与 B 站视频链接中的图片导入现有 ComfyUI 图片任务流；不执行用户提供的原始 `S.exe`，也不修改来源图片。

## 实现

- 页面在「图片与任务」区新增网页 / B 站链接输入框和「提取链接图片」按钮。
- 通用网页优先读取 Open Graph 与 Twitter Card 图片，再读取 `image_src`、`img`、`source`、`data-src` 与 `srcset`。
- B 站视频链接优先通过公开视频信息接口获取封面和标题；接口不可用时回退到普通网页提取。
- 已验证的图片统一进入 `Application.import_images`，沿用已有文件复制、模式选择和任务建立链路；来源页、来源图与类型作为元数据保存。

## 安全边界

- 仅允许公开 HTTP(S) 目标；拒绝本机、私有地址、含凭据链接及非 80/443 端口。
- 禁用系统代理；连接固定到该次 DNS 校验得到的公网 IP，TLS 仍使用原始主机名校验证书；初始地址与每一次重定向均会重新校验。
- 页面最大 1 MiB、单图最大 12 MiB、最大 4,000 万像素；每次最多导入 12 张。
- 单次提取最多解析 36 个候选、发出 16 次请求、累计下载 64 MiB、耗时 45 秒；失败候选、B 站接口与重定向均共享预算。
- 首次请求若为图片可使用 12 MiB 上限，HTML 仍限 1 MiB；解码后仅接受 PNG、JPEG 和 WebP，保存扩展名以实际格式为准。
- 图片以 Pillow 实际解码并校验尺寸，非图片、损坏图、过小图会被跳过或拒绝。
