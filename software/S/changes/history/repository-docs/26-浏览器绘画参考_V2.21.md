# 浏览器绘画参考（任务 #13）

## 接入决定

用户确认把绘画参考作为现有图片输入使用。画布仅在本机浏览器绘制；点击「建立绘画参考任务」后，导出不透明 640×400 PNG，走现有 `/api/import-images`。服务端校验图片、复制到本机 ComfyUI `input/ComfyBatch-V2/imports/<session>`，任务保存 `metadata.source_image`，工作流由已识别的 `LoadImage` 读取。每次建立任务会替换页面当前导入的任务组，不会静默修改已有任务图片。本任务不增加独立的 `reference` 目的或任意 ControlNet 映射；这些能力须单独设计。

## 操作与边界

第一阶段展开「绘画参考」；支持画笔、橡皮、直线、矩形、椭圆、颜色与粗细、撤销/重做、清空、背景 PNG/JPEG/WebP 导入、PNG 导出。背景按比例完整放进画布，剩余区域为白色；导出和导入均为不透明 PNG。最多保留 20 步撤销。空画布不能导出或建任务。导入背景仅允许 20 MB 以下文件；服务端仍独立校验导出后的 PNG，不信任浏览器 MIME 或文件名。

背景在浏览器解码前先读取 PNG/JPEG/WebP 头部尺寸，限制最长边 8192 像素、总像素 1600 万；格式或尺寸无法识别时拒绝，避免很小的高压缩图片耗尽页面内存。图片处理模式沿用页面已有选择；建立任务后应先在第二阶段选用带图片输入的工作流，再执行实际检查。没有 `LoadImage` 的工作流须由现有预检阻断，不能把界面上的预览当成已接入生成。当前工作流的六种「使用目的」菜单不包含单独的 `reference` 项；绘画参考在本版是图片任务的来源，而非新的生成目的。

- Python 集成测试验证 PNG 成为任务、原图进入 ComfyUI input、`source_image` 被编译进 `LoadImage.image`，并验证无图片输入节点时预检阻断。
