# S 桌面版：图片管理 V2.1 方案

本目录保存实际桌面 S V2.42 的独立源码基线及本次图片管理修改。仓库原有 `software/S/src` 是较早的工作台版本，没有桌面版当前使用的图鉴、对比页和资源身份模块，因此保持原目录，避免用旧版覆盖桌面已有功能。

## 使用

进入图鉴，选择“当前文件夹”和“生产日期”。“新建文件夹”创建虚拟目录；用图片上的“组织”复选框选定图片，再通过“组织到文件夹”保存关联。原文件不会移动。

点击图片或详情中的具体风格字段，右侧打开同类浏览区。查询只查当前文件夹，按字段键与去首尾空白后的值精确匹配。未限定文件夹时，以被点击图片所在文件夹为作用域，面板显示该作用域。

面板独立分页、预览和选定。“全选当前结果”包含所有页，跨查询累计选定保留。保留、淘汰及已有收藏夹标记在确认影响数量后，通过既有 `/api/marks/apply` 增量接口保存；图鉴和对比页共享记录。

日期使用 YYYY-MM-DD。只有可信生成记录中的生成/完成时间可进入生产日期；缺失显示“日期未知”。旧文件的修改时间不会继续冒充生产时间，新生成及重做任务会记录生产时间。

## 实现映射

| 方案要求 | 代码 |
| --- | --- |
| 文件夹、日期、字段规范化及精确同类查询 | `tools/atlas_management.py` |
| 稳定身份、外部改名后的标记及元数据恢复 | `tools/atlas_resources.py` 与组织文档 |
| 用户文件夹持久化 | SQLite resources.sqlite3 内 `_organization.json` 版本化文档 |
| 主图鉴与侧区独立状态 | `tools/atlas_management.js` 的 MG 与原图鉴状态 |
| 既有图鉴集成、页面及组织修订指纹 | `tools/build_atlas.py`、`tools/atlas_server.py` |
| 真实生成记录与 PNG/manifest 风格字段 | `tools/style_atlas.py` |
| 新生成及重做的可信生产时间 | `src/comfybatch_v2_core.py` |

保留本地桌面基线已有的按内容去重、收藏、评级、对比、参数工作台、预设及启动器。没有加入自动聚类、自动移动、自动合并或自动删除图片。

## 验证与构建

运行 `python -B run_tests.py`；Windows 系统代理环境需设置 `NO_PROXY=127.0.0.1,localhost`。验证时设置 `ATLAS_NO_DESKTOP=1`，避免测试页面同步到真实桌面。

桌面源码全量回归：636 项，635 通过，1 跳过（外部 XLSX 环境）。另运行 `node tests/check_atlas_management_js.js` 与 `node tests/check_atlas_duplicates_js.js`，均通过。10000 条同类查询的测试门槛为 1 秒以内；该查询包含完整命中身份及分页明细。

构建：安装 Pillow、PyInstaller 后，在 `src` 下执行 `python -m PyInstaller --noconfirm --clean S.spec`。

发布源码不含用户图片、收藏记录、评级记录、索引缓存或资源数据库。首次安装种子为空；升级继续读取现有 AppData 数据。系统评级种子同样为空，避免把本机路径及历史评级打进公开仓库。
