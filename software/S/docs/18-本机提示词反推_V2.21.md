# V2.21：本机提示词反推（2026-09-23）

## 用户可见行为

- 每个已导入的图片任务显示“本机反推提示词”。
- 点击后只向配置的本机 ComfyUI 提交文本反推工作流，并把结果回填到该任务的正面提示词。
- 首选 `easy imageInterrogator → H3ShowText`；首选节点缺失或执行失败时自动回退
  `BLIPCaption → H3ShowText`。
- 缺少 `LoadImage`、`H3ShowText` 或两种反推节点时，界面给出要安装或启用的节点名称，
  不静默失败，也不调用外部 API。

## 安全边界

- 路由仍由仅监听 `127.0.0.1` 的 S 内部服务提供。
- 调用只接受当前导入批次的任务编号；后端再次确认图片位于 ComfyUI `input` 目录且真实存在。
- 反推节点、ComfyUI prompt id、是否仅本机运行和更新时间写入任务元数据，便于后续审计。

## 验收范围

- 首选节点选择、缺失回退、运行时失败回退、缺依赖提示、BLIP 参数和文本型历史结果均有单元测试。
- 页面按钮提供稳定的 `data-agent-action="interrogate-image"` 和可访问名称。
- 发布仍需经过全量测试、公开内容扫描、独立审查、PR 合并、候选包隔离验收及桌面替换。
