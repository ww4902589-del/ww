# 紧凑审图与半透明信息浮层（任务 #10）

日期：2026-09-24 ｜ 分支：`handoff/local-s-review` ｜ 基点：`c9545b8`（main，含 #4 作品库）

## 这是什么

审图页（阶段 4「成图预览与确认」）的两个补强：

1. **缩略图墙（`wall` 密度档）**——密度下拉新增第四档，是比「紧凑」更狠的档位：
   150px 小图一格、正方形裁切、信息块（kv 表 / 生成详情 / 提示词块）全部收起，
   只留图、标题行（含勾选框与徽标）和缩小的操作按钮。
   给「几十上百张图快速过一遍」的场景用。
2. **半透明信息浮层（`.thumb-overlay`）**——鼠标悬停缩略图时，
   图上浮出一层暗色渐变信息条：编号、尺寸（含放大倍数）、种子、确认状态
   （疑似重复会标注）、提示词摘要（前 140 字，最多 3 行）。
   **所有密度档都可用**——墙档下它是唯一的信息入口，其他档位下是免点开的速览。
   浮层是纯视觉增强，对读屏器隐藏（信息在 kv 表里有完整版）。

## 设计取舍（写下来防止后人"优化"掉）

- **浮层由纯 CSS 驱动**（`.thumb:hover` + `opacity` 过渡），
  没有任何 JS 事件监听。悬停渲染不该花 JS 的钱。
  CSS 里的 `:focus-within` 是**为 #11 预留**的死选择器（当前缩略图内无可聚焦元素），
  #11 做键盘导航时若让卡片可聚焦即自动生效；届时若仍不需要应删除。
- **`pointer-events:none` 是硬性要求**：浮层盖在整张缩略图上，
  如果它能接收指针事件，"点图看原图"就会在浮层出现后失效——这是这类浮层
  最常见的回归。有测试钉住（`test_overlay_is_css_driven_and_never_blocks_clicks`）。
- **`aria-hidden="true"`**：浮层是卡片 kv 表的复制视图，对读屏器隐藏避免双读。
- **墙档必须保留操作按钮**：收起信息块可以，藏掉「通过/打回/记录问题」和勾选框
  就没法审图了。有测试钉住（`test_wall_mode_hides_verbose_blocks_but_keeps_actions`）。
- **密度选择记忆沿用既有机制**（`localStorage` 键 `comfybatch-review-density`），
  `setReviewDensity` 本就是按值加 `density-<value>` 类，`wall` 无需改 JS 逻辑。
- 默认档位仍是「紧凑」：墙档是 opt-in，不改变老用户的既有习惯。
- 浮层底色用暗色渐变（`rgba(10,14,20,…)`）：它浮在**照片内容**上，
  暗底白字在亮色/暗色两套主题下都可读，不做主题分支。

## 不做什么（与 #11 的边界）

编号跳转、卡片高亮（既有 `is-active` 之外的增强）、滚动定位、键盘快捷键
全部属于任务 #11，本任务**没有引入任何键盘事件**。

## 独立审查与修复记录（2026-09-24）

只读独立审查报出 1 HIGH + 1 MEDIUM + 3 LOW + 5 NIT，处理如下：

| 级别 | 发现 | 处理 |
|---|---|---|
| HIGH | `setReviewDensity` 的 remove 清单漏了 `density-wall`——选过墙档再切回其他档，类残留且 CSS 层叠下 wall 胜出，**界面永久卡在墙档** | 改为按档位清单 `[…,'wall']` forEach 移除；新增回归测试 `test_switching_away_from_wall_removes_the_wall_class` |
| MEDIUM | `pointer-events:none` 断言整文件搜索，`.busy` 里早有同款声明，**永真** | 收窄到 `.thumb-overlay` 规则块内部断言 |
| LOW | `:hover` / 字段名断言同样是永真 | 改为断言 `.thumb:hover .thumb-overlay` 联合选择器（悬停驱动写在浮层上） |
| LOW | HANDOFF.md 行尾被整文件写成 CRLF（基点全 LF） | 按基点还原为 LF |
| LOW | `x.upscale_factor` 插值未过 esc()（非用户输入、与既有 kv 行一致，非现实 XSS） | 统一 `esc(String(...))` |
| NIT | 浮层种子只显示第一个 | 加 `(+n)` 计数 |
| NIT | `.slice(0,140)` 可能切断 UTF-16 代理对 | 改为按码点展开截断 |
| NIT | `:focus-within` 死选择器且文档声称"键盘聚焦" | 文档改为"为 #11 预留"，选择器保留 |
| NIT | `.density-wall .review-card` 里 `grid-template-columns` 在 flex 容器上无效 | 删除 |
| NIT | 无图卡片也渲染浮层 | **保留**：编号/状态在无图卡片上同样有用，审查者亦认为无害 |

修复后全量 **508 项：通过 507、失败 0、跳过 1**（基线 502 + 本次 6 项）。
