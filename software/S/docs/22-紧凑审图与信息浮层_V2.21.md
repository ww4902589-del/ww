# 紧凑审图与半透明信息浮层（任务 #10）

日期：2026-09-24 ｜ 分支：`handoff/local-s-review` ｜ 基点：`c9545b8`（main，含 #4 作品库）

## 这是什么

审图页（阶段 4「成图预览与确认」）的两个补强：

1. **缩略图墙（`wall` 密度档）**——密度下拉新增第四档，是比「紧凑」更狠的档位：
   150px 小图一格、正方形裁切、信息块（kv 表 / 生成详情 / 提示词块）全部收起，
   只留图、标题行（含勾选框与徽标）和缩小的操作按钮。
   给「几十上百张图快速过一遍」的场景用。
2. **半透明信息浮层（`.thumb-overlay`）**——鼠标悬停（或键盘聚焦）缩略图时，
   图上浮出一层暗色渐变信息条：编号、尺寸（含放大倍数）、种子、确认状态
   （疑似重复会标注）、提示词摘要（前 140 字，最多 3 行）。
   **所有密度档都可用**——墙档下它是唯一的信息入口，其他档位下是免点开的速览。

## 设计取舍（写下来防止后人"优化"掉）

- **浮层由纯 CSS 驱动**（`:hover` / `:focus-within` + `opacity` 过渡），
  没有任何 JS 事件监听。悬停渲染不该花 JS 的钱。
- **`pointer-events:none` 是硬性要求**：浮层盖在整张缩略图上，
  如果它能接收指针事件，"点图看原图"就会在浮层出现后失效——这是这类浮层
  最常见的回归。有测试钉住（`test_overlay_is_css_driven_and_never_blocks_clicks`）。
- **`aria-hidden="true"`**：浮层是卡片 kv 表的复制视图，对读屏器隐藏避免双读。
- **墙档必须保留操作按钮**：收起信息块可以，藏掉「通过/打回/记录问题」和勾选框
  就没法审图了。有测试钉住（`test_wall_mode_hides_verbose_blocks_but_keeps_actions`）。
- **密度选择记忆沿用既有机制**（`localStorage` 键 `comfybatch-review-density`），
  `setReviewDensity` 本就是按值加 `density-<value>` 类，`wall` 无需改 JS 逻辑。
- 默认档位仍是「紧凑」：墙档是 opt-in，不改变老用户的既有习惯。
- 浮层底色用暗色渐变（`rgba(10,14,20,…)`）：它浮在**照片内容**上，
  暗底白字在亮色/暗色两套主题下都可读，不做主题分支。

## 不做什么（与 #11 的边界）

编号跳转、卡片高亮（既有 `is-active` 之外的增强）、滚动定位、键盘快捷键
全部属于任务 #11，本任务**没有引入任何键盘事件**。

## 已知限制

- 浮层提示词摘要固定 140 字 / 3 行，不看全文——全文在「查看生成详情」里。
- 墙档列宽 150px 起步，极小窗口下会折成单列（与既有栅格行为一致）。
