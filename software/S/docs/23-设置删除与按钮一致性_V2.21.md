# 设置删除与按钮一致性（任务 #5）

## 范围

本任务处理生成配置页的风格／LoRA 预设、LoRA 触发词档案、工作流参数默认值三类设置。服务端已有预设与档案的墓碑删除机制，本次保留该机制，修正页面在保存、删除和失败后的按钮与状态反馈。作品库删除属于任务 #4；替换规则、任务队列和审图操作不在本次范围。

## 行为

- 没有选中风格／LoRA 预设时，「更新」「重新载入」「删除」按钮禁用。删除成功后清除选择与名称，更新任务引用和列表，并显示成功提示；失败时保留原选择并显示错误。
- 只有确实保存过 LoRA 档案时才显示「删除档案」。即使档案中的触发词为空，仍可删除。保存后按钮立即出现；删除后按钮立即消失，页面当前已填的 LoRA 值保留。随后只读取该 LoRA 的资源状态，不重建整个配置页，以免重置工作流与模型选择。
- 「清除已保存默认值」使用服务端返回的参数状态更新工作台；失败时保留旧状态并只显示错误。「清空未应用输入」也只在读取成功后报告成功。
- LoRA 删除按钮传递列表索引，由当前行查找文件名，避免文件名中的引号破坏按钮事件。
