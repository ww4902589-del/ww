# 审图编号导航（任务 #11）

日期：2026-09-24 ｜ 分支：`handoff/local-s-navigation` ｜ 基点：`b402d14`

## 范围与行为

- 阶段 4 的工具栏提供“跳转编号”输入框和“定位”按钮，`G` 可聚焦输入框，输入编号后按 Enter 也可定位。
- 编号按当前审图结果的 `index` 精确匹配，不把输入值当作数组位置；空值、非正整数、过大整数和当前批次不存在的编号显示就地反馈，保留原来的选中卡片。
- 成功定位后切换高亮、把卡片滚动到视口中部并聚焦卡片。反馈区使用 `role=status` 与 `aria-live=polite`；卡片可被程序聚焦，缩略图信息浮层随之显示。
- `J` / `K` 在当前结果中前后移动，包含尚无成图的卡片；`Y` / `N` / Enter 的确认、打回和原图操作仍只对已有成图的卡片有效。
- 全局审图快捷键仅在阶段 4 生效，且避开输入控件、可编辑内容、按钮、链接、展开摘要、打开的对话框与抽屉；带 Ctrl/Alt/Meta/Shift 的组合键由浏览器或其他控件处理。抽屉打开时的 Escape 关闭行为保留。

## 验收

1. 当前批次结果索引为 2、7、13 时，输入 7 能选中并定位第 7 张；输入 3 显示不存在，原选中项不变。
2. 从未选中状态按 J 到第一张、按 K 到最后一张；从无图卡片可继续移动，Y/N/Enter 不对无图卡片执行审图操作。
3. 在其他阶段、输入框、对话框和抽屉中，审图快捷键不触发；打开的抽屉可由 Escape 关闭。
4. 卡片获得焦点时，清晰高亮并显示已有信息浮层；鼠标点击原图、勾选和审图按钮仍按原入口工作。

针对性测试执行实际页面函数与键盘处理器，覆盖上述正常、缺失编号和作用范围。全量测试、编译、词法与公开内容检查结果记录在 `HANDOFF.md`。
