# 本地风格组合推荐（任务 #12）

日期：2026-09-24 ｜ 分支：`handoff/local-s-style-recommendation` ｜ 基点：`7adaa6e`

## 范围

在阶段 2 的“风格组合”区加入本地搭配建议。主风格取现有组合的第一项；组合为空时，取当前下拉框选中的具体风格。推荐只读取本机 ComfyUI 风格目录已扫描进入 `inventory.styles` 的条目，不发网络请求、不读取 LoRA 清单，也不修改 LoRA 选择或档案。

## 推荐与应用规则

- 只推荐有模板文字的本地风格。以中英文风格名、风格库名和模板文字的共有关键词排序；显示实际匹配线索，最多列出 3 个搭配。
- 动漫/插画与摄影/写实等明确不同媒介的条目不互荐；名称和库名同时给出两种媒介线索的条目也不进入自动推荐。已选风格、空模板或没有共同线索的条目不推荐；不足时明确告知，不编造搭配。
- 点击建议只把相应风格加入当前组合。组合为空时先加入主风格再加入建议风格；已有风格不被替换。沿用既有“最多 4 个风格”限制。
- 应用时再次核对主风格、建议风格的标识和用于推荐的目录字段指纹，避免同名条目模板或媒介变化后使用过期建议。应用后走现有风格组合渲染与生成配置路径；是否保存为预设仍由用户使用原有入口决定。

## 验收

1. 当前主风格是“水彩动漫”，本地目录有相关“柔和水彩画”、摄影类“水彩摄影”和空模板条目时，只推荐前者，且显示匹配线索。
2. 组合为空时应用建议，得到主风格加搭配风格；已有主风格时只增补搭配，不覆盖其他已选风格。
3. LoRA 选择和档案在推荐、应用和目录变化失败路径中均不变；不产生远程请求。
4. 风格目录或主风格变化后（包括同名条目的模板变化），旧建议不能应用；已满 4 个风格时提示先移除；没有可靠匹配时明确说明。
5. 正常配置、预设保存和生成仍通过既有风格编译/原生组合器路径，不增加新的生成后端分支。

独立行为测试调用页面中实际推荐与应用函数，覆盖正常、媒介不匹配、空模板、重复选择、目录变化和 LoRA 不变。全量测试、编译、前端词法及公开内容扫描结果记录在 `HANDOFF.md`。
