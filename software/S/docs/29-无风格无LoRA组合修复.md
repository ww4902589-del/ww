# 无风格＋无 LoRA 组合

需求：允许不加入任何风格或 LoRA 就生成；直接更新桌面软件，保留已有设置。
基点：`origin/main` 的 `3aec072`，独立分支 `handoff/local-s-plain-combination`。

- 配置页新增「无风格＋无 LoRA」按钮：清空全局组合、切换到「无风格（原始提示词）」模式。
- 不提交下拉框默认风格；允许命名、保存、载入空预设，也可分配给单独任务，覆盖全局组合。
- 无风格模式绕过 `easy stylesSelector`。当该模式的 LoRA 列表也为空时，绕过工作流自带的标准 `LoraLoader` / `LoraLoaderModelOnly`，复接原始模型/CLIP；无法安全复接则阻断而非偷偷加风格。
- 原有风格组合和 LoRA 功能保留；任务级非空预设仍优先覆盖全局。自定义非标准资源节点不承诺通用绕过。
- 保留负面提示词、主体保护与其他生成参数；「原始提示词」表示不添加风格模板，不表示取消所有提示词处理。

发布前验证：空预设持久化、页面实际提交行为、标准资源复接、真实编译图，外加全量测试、编译、前端词法检查。实机 GPU 生图尚未验收，不据自动测试宣称真实成图完成。
